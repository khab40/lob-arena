# ARD-0014: Multiuser Platform Foundation

Status: Retired implementation; identifier and historical decision retained.
Disposition date: 2026-10-08.

The earlier workspace/user/role/case/audit foundation is archived. Its original
design is not evidence that a current shared service enforces those controls.
Active diagrams must show implemented boundaries; a planned identity block
cannot be used as an authorization claim.

The [original decision](../../evidence/deployment-2026-07-14-1412/architecture/docs/architecture/ARD-0014-multiuser-platform-foundation.md)
is retained unchanged. Restore or replace capabilities only within the approved
[secure-demo story #91](https://github.com/khab40/lob-arena/issues/91), with
explicit backend access control and verified acceptance. This disposition
restores documentation navigation only, not source code or feature scope.

# Frontend

Vite React UI for the arena demo.

## Views

- Arena: live order book, charts, agent feed, detector confidence, scenarios, and incidents.
- Data Ingestion: validate and register local historical datasets.
- Control Panel: Nebius configuration, investigation and experiment evidence.
- About: project positioning, safety framing, and architecture summary.

## Local Development

```bash
pnpm install
pnpm run dev
```
